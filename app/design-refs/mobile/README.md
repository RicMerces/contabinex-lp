# Referências de design — telas MÓVEIS (node 1-2 do Figma)

Exporte aqui os PNGs das telas mobile do Figma. Vou reconstruir o layout móvel
de cada tela de funil para bater com esses designs.

## Como exportar (Figma)
Selecione cada frame mobile → painel direito → **Export** → PNG (2x de
preferência) → salve nesta pasta.
